SAVE asks once for the site's animations folder and then writes the file in place, after checking nobody changed it on disk since it was loaded. Only the edited values change; everything else in the file is kept byte for byte. Two of the animations are loaded with a ?v= stamp on their page (server.js, volcano.js), so commit through the pre-commit hook or run npm run fix:cachebust.
