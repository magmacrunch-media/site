COUNTING IN BINARY

You count with ten digits, 0 through 9, whereas a computer counts with only two, 0 and 1. That is all that binary means.

Each of those digits is a bit. A tile holds four bits in a row, and each bit is worth twice the one to its right, so the columns are worth 8, 4, 2 and 1. The number on a tile is the sum of the columns that hold a 1.

8 4 2 1
0 0 0 1 = 1
0 0 1 0 = 2
0 0 1 1 = 2+1 = 3
0 1 0 1 = 4+1 = 5
1 1 1 1 = 8+4+2+1 = 15

Four bits can therefore hold nothing larger than 15. Two bits top out at 3 and eight bits at 255, which is all that the bit modes are.

A GATE IS A RULE FOR ONE BIT

Before it touches a whole number, a gate is a rule about one bit against one bit: two bits in, one bit out. There are only four such rules, and each fits in four lines, read as "in, in, out".

NOW DO IT TO A WHOLE NUMBER

A gate does not know what 5 is. It lines up the two tiles' bits column by column, applies its one rule to each column, and reads the answer back as a number, so nothing carries the way it does in addition.

8 4 2 1
0 1 0 1 5
0 0 1 1 3
⊕
0 1 1 0 = 4+2 = 6

In the 1 column both bits are 1, so XOR gives 0. In the 2 and 4 columns exactly one bit is 1, so each gives 1, and in the 8 column neither is. The result is 0110, which is 6.

The same two tiles through the other two gates meet the same bits under a different rule, and so give a different number:

NOT needs only one tile, since it flips all four bits: ¬5 turns 0101 into 1010, which is 10.

That is all of binary and all four gates. Everything past this point is the game.

As in 2048, you swipe, or use the arrow keys, to slide every tile on a 4 by 4 grid in one direction.

THE GOAL

  • Score points by combining tiles.
  • Last as long as you can, since the game ends only when the board is full and no move is left.

As a warm up, play 2^N, our take on 2048, at magmacrunch.com/arcade.

EQUAL TILES MERGE

Two equal tiles merge into one tile of the same value rather than double it, because in Boolean logic A ∨ A = A, a rule called idempotence. Each merge scores the tile's value.

  • 1 and 1 make 1
  • 2 and 2 make 2
  • 7 and 7 make 7

Two different numbers don't merge on their own. They can only be combined with a gate: ⊕, ∨ or ∧.

How the gates are used

  • ¬ slides into any number, from either side.
  • Two ¬ that meet cancel each other, so both clear and score nothing.
  • ⊕ ∨ ∧ sit between two numbers: number, gate, number.
  • A gate whose result is 0 clears its tiles and scores nothing, as in 0011 ⊕ 0011 = 0000.

THE CEILING AND OVERFLOW

Each mode has a ceiling, the largest number its bits can hold, which for N bits is 2N − 1.

2-BIT 3
3-BIT 7
4-BIT 15
5-BIT 31
6-BIT 63
7-BIT 127
8-BIT 255
GAUNTLET each in turn

No gate can take a tile past the ceiling. NOT of the ceiling, however, flips every bit to 0, and since no tile can hold 0, the tile clears and pays three times the ceiling. That's the only way to overflow.

2-bit: ¬11 = 00, an overflow worth +9
4-bit: ¬1111 = 0000, worth +45

GAUNTLET

Gauntlet is the survival mode, in which the board gains a bit every time you build its ceiling.

  • It begins at 2 bits, with a ceiling of 3.
  • Building the ceiling adds a bit, and the banner at the top names the next target.
  • It runs 2, 3, 4, 5, 6, 7 and 8 bits, and 8 bits is the last.

Start at 2-BIT, where the ceiling is 3. Make 3 with 1 ∨ 2, and the board becomes 3-BIT, with a ceiling of 7. Make 7 by any route, and it becomes 4-BIT, and so on through 8-BIT.

SCORING

  • A gate or a merge scores the value it produces.
  • The first time you build a value large enough to count, it also pays a height bonus of twice that value.
  • An overflow scores three times the ceiling.

In 4-bit, the first 15 scores 15, plus a height bonus of 30, for 45 in all.
