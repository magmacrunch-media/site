adenosine

lightweight game engines by magmacrunch media

A collection of lightweight web game engines by magmacrunch media. TypeScript and JavaScript, zero runtime dependencies, built for browsers. Powering the magmacrunch web arcade since 2026.

install

CDN, no build step:

<script src="https://cdn.jsdelivr.net/npm/@magmacrunch/adenosine-rpg@0.4.0/dist/index.global.js"></script>

npm:

npm install @magmacrunch/adenosine-rpg

the name

After “Adenosine” by Texas Hold’Em Lava Dome, published by magmacrunch music. Adenosine is the molecule that builds sleep pressure, which is why the iOS shell is called hypnopompia.
