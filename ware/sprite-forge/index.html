SPRITE//FORGE

a pixel-art sprite and animation editor, for the sprites in our games

▶ Open SPRITE//FORGE lite

Runs in your browser. Nothing to install.

What it does

Draw a sprite a frame at a time and watch it move. Onion skin shows up to four frames either side, a frame can hold for several beats, and the surface preview wraps the frame round a sphere, a cylinder or a billboard to see how it sits in a 3D scene. A character's views sit side by side, and a mirrored view follows its source until you draw on it.

Colours have names. A character template marks its parts as slots, so you recolour the jacket or the hair by name instead of hunting for the right hex, and you can make a slot out of any swatch on any sprite. Several sprites can share one palette in one project.

It exports a PNG sheet on a plain grid, which adenosine, magnolia, texastoast and GameMaker all read, and saves the whole project as a .forge file you can open again.

Lite

The browser version has all of the drawing, the animation and the .forge files. In Chrome, Edge and other Chromium browsers it can also save back over the file you opened; anywhere else every save downloads a new file.

The desktop version adds targets: export goes straight into a game's repo, in the form that game wants, from a magnolia sprite sheet to C# source for Godot. It also has the menu bar.

Built on

magma-kit. The desktop version isn't out yet.
