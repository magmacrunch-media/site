PUNCH//ROLL

a chiptune piano roll, in the spirit of the old versions of FL Studio

▶ Open PUNCH//ROLL

It runs in this browser tab, with nothing to install.

What it does

Write notes on a grid, one row per pitch, and hear them on the sounds of an old game console: two pulse waves, a triangle and noise to start with, and up to six tracks.

  • a step sequencer for drums, and a sample of your own on any track
  • 19, 24 or 31 notes to the octave as well as the usual 12, swing, and tempo changes partway through a song
  • step entry from the computer keyboard, or play notes in from a MIDI keyboard
  • File > Append, which plays another song straight after this one
  • an oscilloscope you can pop out into its own window
  • export to WAV, FLAC, MP3 or Ogg

In a browser

For now this is the same program as the desktop app, run without its desktop half, so the music side works the same. What changes is how it reaches files and devices:

  • Save downloads a new file each time instead of writing over the open one, and there is no Save As.
  • Open and Append use the browser's file picker. A song cannot be opened by double-clicking it.
  • A MIDI keyboard needs a browser with Web MIDI, which in practice means Chrome, Edge or another Chromium browser.
  • The popped-out scope cannot be kept on top of other windows.

The song you are working on, the samples you load and your settings are kept in this browser between visits. Save to a file to keep a song anywhere else.

Built on

PUNCH//ROLL is a magmacrunch desktop app, built on magma-kit, with its synth from adenosine. The desktop version is not distributed yet.
